# Session 2026-05-02

Sammanfattning av routingoptimering och kalibrering.

## Routeplanner

- Flyttade `accidentHistory` och `disturbances` närmare GraphHoppers vägkostnad:
  - `accidentHistory` bygger dynamiska custom areas/penalty zones runt risksegment från `risk_in_bbox`.
  - `disturbances` bygger dynamiska custom areas/penalty zones runt aktiva störningspunkter från `disturbances_public`.
  - Penalty zones läggs in i GraphHoppers `priority`-modell och kräver `ch.disable: true`.
- Skärpte `highSpeed` custom model:
  - lägre prioritet för `MOTORWAY`, `TRUNK`, `PRIMARY`, `max_speed >= 90` och `max_speed >= 80`.
  - extra diversifierad highSpeed-kandidat används för att hitta fler låg-/noll-högfartskorridorer.
- Basrutten behålls som jämförelse. UI:t rankar fortfarande kandidater mot de toggles användaren faktiskt valt.

## Tidsbudget

- Tidsbudgeten är nu ett hårt filter för visade alternativ.
- Rutter över vald extra restid filtreras bort från API/UI-förslag.
- Sliderändring med aktiva filter triggar ny jämförelse mot `/api/route`.
- `∞` öppnar sökutrymmet och tillåter längre undvik-rutter.

## Verifierade ruttfall

- Floda -> Göteborg:
  - `highSpeed` genererar flera kandidater med kraftigt lägre högfartsexponering.
  - `maxExtraMinutes: 10` filtrerar bort längre undvik-rutter.
  - `maxExtraMinutes: null` returnerar längre kandidater, inklusive noll-högfart.
- Floda -> Borås:
  - `highSpeed` + `∞` returnerar nu även noll-högfartskandidat utan att användaren behöver slå på `disturbances`.

  - grafen visar compute-RAM, inte database size på disk.
  - Free tier-risken för read-only ligger på database size-gränsen, medan RAM behöver följas via swap/latens/OOM-symptom.

- Migrationen kördes manuellt i Supabase SQL Editor och Advisor visade därefter `no issues`.

## Dragbar Rutt

- Implementerade Google Maps-liknande dragning av primärrutt i MapLibre:
  - primärrutten har bred osynlig hit-line.
  - hover visar tooltip och en liten punkt som snappar mot ruttlinjen.
  - dragpunkten ligger centrerad under pekaren och behåller pointer-cursor.
- Tog bort synlig `Lägg till ett stopp`-knapp.
- Manuella drag skapar en dold via-punkt internt, men UI:t visar fortsatt bara Från/Till.
- Nya drag ersätter tidigare dold via-punkt i stället för att stapla flera omvägar, så användaren kan flytta tillbaka efter dead-end eller dåligt val.
- Under drag körs throttlad preview via `/api/route` med `preview: true`.
  - preview hoppar över Supabase-score och hämtar bara enkel GraphHopper/OSRM-rutt.
  - vid släpp körs full rutt + `avoidScores`/`exposure`.
